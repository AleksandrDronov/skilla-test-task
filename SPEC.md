# Hover-состояние строки

При наведении на строку необходимо использовать поведение из макета.

Вместо обычного отображения длительности появляется блок управления записью звонка.

Состав блока:

- длительность записи;
- кнопка Play / Pause;
- прогресс воспроизведения;
- кнопка скачивания записи.

Все размеры, стили и расположение элементов должны быть получены из Figma.

---

# Получение записи звонка

При нажатии на кнопку воспроизведения:

1. Выполнить запрос получения записи звонка через API.
2. Получить аудиофайл.
3. Создать Blob URL.
4. Создать экземпляр Audio.
5. Запустить воспроизведение.

Пример реализации:

```ts
const blobUrl = URL.createObjectURL(blob)
const audio = new Audio(blobUrl)
audio.play()
```

---

# Скачивание записи

Необходимо реализовать возможность скачать запись звонка.

При нажатии на кнопку скачивания:

- скачивается полученный аудиофайл;
- либо открывается ссылка на скачивание.

---

# Ограничение воспроизведения

Одновременно может воспроизводиться только одна запись.

При запуске новой записи:

- предыдущая запись останавливается;
- активный плеер переключается на новую запись.
